# VEXORA

**Student success, reimagined.**

VEXORA is a National Student Success Ecosystem built around learning, projects, competitions, opportunities, communities, and student direction.

This repository contains the current public project preview and case study. It is intentionally presented as a project in development rather than a finished product.

## Routes

- `/` — VEXORA coming-soon project preview
- `/case-study` — 20-part VEXORA story with a navigable table of contents

## Stack

- Next.js
- React
- TypeScript
- CSS

## Development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
