# VEXORA

**The ecosystem, research and case-study layer behind BEAT.**

VEXORA is the parent project. It contains the problem research, evidence, case studies, product story and competition documentation.

## BEAT

**Beat your ideas.**

BEAT is VEXORA's social platform product — a student social network for discovering people and ideas, sharing projects and questions, collaborating, and finding opportunities.

The product is separated from the VEXORA case-study layer:

    VEXORA/
    ├── case-study/      # research, evidence and presentation material
    └── BEAT/            # the working social platform
        ├── frontend/    # React
        ├── backend/     # Django
        └── docs/        # product and technical docs

## Product loop

**Discover → Connect → Beat → Collaborate → Showcase → Opportunities**

## Technical direction

BEAT uses **JavaScript + React** for the frontend and **Python + Django + Django REST Framework** for the backend.

The existing implementation is being organized under BEAT; VEXORA remains the parent research and case-study layer.
