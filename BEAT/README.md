# BEAT — by VEXORA

**Beat your ideas.**

BEAT is the social platform inside the VEXORA ecosystem.

VEXORA is the parent project/brand and case-study hub. BEAT is the actual student social network: a place to share ideas, projects, questions, discoveries and collaborations.

## Product identity

- **VEXORA** — parent ecosystem, research and case studies
- **BEAT** — social network / product
- **Tagline** — Beat your ideas.

## Core loop

**Discover → Connect → Beat → Collaborate → Showcase → Opportunities**

In BEAT, a post is a **Beat**. Users can share an idea, project, question, experiment or discovery and build conversations around it.

## Folder structure

    BEAT/
    ├── README.md
    ├── frontend/        # React social application
    ├── backend/         # Django + Django REST API
    └── docs/            # BEAT product and technical documentation

The existing React/Django implementation in this repository is being organized under BEAT while VEXORA remains the parent case-study/product-story layer.

## Technical direction

- Frontend: JavaScript + React
- Backend: Python + Django + Django REST Framework
- Database: SQLite for development; production database can be added later
- API: REST

## Important

BEAT uses its own product language and identity. Do not treat BEAT as another VEXORA case-study page or as a learning dashboard. It is the social product demonstrated by the VEXORA project.
